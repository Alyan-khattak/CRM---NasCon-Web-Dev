## Directory Index

- [Branch Inventory](branch-inventory.md): Full audit of remote and local branches, unique commits, and synchronization analysis.
- [Baseline & Scope](baseline-and-scope.md): Testing baseline definition, environment boundaries, architectural scope, and exclusion justifications.
- [Requirements Traceability Matrix](requirements-traceability.md): Complete mapping of problem statement requirements (F1–F5, I1–I5, Q1–Q14) to test cases and verification status.
- [Test Plan](test-plan.md): 360-degree test strategy, environments, tools, entry/exit criteria, and risk mitigations.
- [Test Case Register](test-case-register.md): Granular test cases covering functional, security, concurrency, performance, and integration behaviors.
- [Test Execution Log](test-execution-log.md): Real-time sequential execution log with timestamps, commit hashes, commands, and results.
- [Defect Register](defect-register.md): Discovered defects, severity, priority, reproduction steps, root cause analysis, fix commit, and retest evidence.
- [Security Assessment](security-assessment.md): OWASP Top 10 evaluation, authentication, authorization, IDOR/BOLA, secrets handling, and tamper resistance.
- [Dependency & Supply Chain](dependency-and-supply-chain.md): Audit of runtime packages, security vulnerabilities, deprecations, and lockfile consistency.
- [Performance & Scalability](performance-and-scalability.md): Latency benchmarks, concurrent lead intake, database query profiling, and stress evaluations.
- [Integration Validation](integration-validation.md): Verification of messaging (Twilio/Retell), payments (Stripe/Simpaisa), calendar (Google Calendar), notifications, and webhook idempotency.
- [Regression Report](regression-report.md): Post-fix verification, side-effect analysis, and release candidate stability.
- [Coverage Report](coverage-report.md): Code coverage, requirement coverage, and critical journey execution rates.
- [Release Gate Decision](release-gate.md): Final sign-off verdict, release criteria checklist, and deployment readiness summary.
- [Evidence Locker](evidence/README.md): Logs, benchmark results, raw request/response captures, and audit artifacts.
