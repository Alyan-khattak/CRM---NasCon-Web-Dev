# QA Evidence Locker

This directory stores reproducible evidence generated during the 360-degree quality assurance testing lifecycle.

## Contents & Organization

- `raw_logs/`: Test run transcripts, raw terminal outputs, and execution traces.
- `coverage/`: Test coverage metrics, branch coverage statistics, and HTML reports.
- `benchmarks/`: API latency percentiles, concurrent load test outputs, and DB query analysis.
- `security/`: Secret scans, authorization audit traces, and vulnerability assessment outputs.
- `screenshots/`: Visual UI evidence (if applicable).

> [!IMPORTANT]
> In accordance with Git safety and security mandates, no real customer credentials, API keys, session tokens, or sensitive monetary numbers are ever recorded in evidence logs.
