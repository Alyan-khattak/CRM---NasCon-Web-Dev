# Documentation Package — Unified Business Management Platform

This directory contains the seven core Markdown documents and the implementation roadmap:
- `PRD.md` — product requirements and scope
- `TRD.md` — technical constraints and unresolved stack decisions
- `Architecture.md` — intentionally blocked architecture placeholder until requirements/MVP approval
- `appFlow.md` — requirement-derived application and workflow behavior
- `database.md` — source-supported logical data inventory, not a finalized schema
- `design.md` — UI/UX requirements and clearly labeled proposals
- `Rules.md` — constraints for AI coding assistants
- `phases.md` — proposed, gated implementation roadmap

## Governance
The problem statement and explicitly confirmed stakeholder clarifications are authoritative. Draft documents do not themselves approve requirements, MVP scope, technology, vendors or architecture. Read `PRD.md` open questions and `phases.md` blockers first.

No application code was created as part of this documentation package.
